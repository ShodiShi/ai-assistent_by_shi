# ai-assistent_by_shi

Jarvis — полностью локальный голосовой ассистент для Windows 10 (в разработке). Подробности
архитектуры и планов по этапам — в `docs/superpowers/specs/`.

## Этап 1 — текстовое ядро

На этом этапе `Jarvis.Core` работает без звука: команды вводятся с клавиатуры в консоли, разбираются
уровнями 1 (правила) и 2 (embedding-сходство), выполняются через реальные инструменты Windows
(открытие/закрытие приложений, управление громкостью, питание/сон/блокировка, сводка по системе),
ответ печатается в консоль.

Требования: .NET 8 SDK (или новее, с установленным net8.0 runtime).

1. Скачайте embedding-модель для уровня 2 (опционально — без неё работает только уровень 1,
   разбор по правилам; при отсутствии модели ядро сообщит об этом в лог и продолжит работать):
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts/download-models.ps1
   ```
   Уровень 2 (embedding-сопоставление) откалиброван на реальной скачанной модели: 40 из 44
   распознаваемых фраз тестовой фикстуры резолвятся верно при нуле ложных срабатываний на
   заведомо нераспознаваемых фразах (порог `embedding_threshold: 0.90` в `config/config.yaml`,
   детали — в `OnnxEmbeddingModelIntegrationTests`). Это калибровка на 50 фразах, а не полноценная
   продакшн-оценка — при добавлении новых команд стоит перепроверить.
2. Запустите ядро из корня репозитория (конфиги читаются по относительным путям `config/...`):
   ```bash
   dotnet run --project src/Jarvis.Core
   ```
3. Введите команду, например `открой хром` или `как там батарея`. Для опасных команд (например
   `выключи ноут`) ассистент попросит подтверждение — ответьте `да` для выполнения или `отмена`
   для отказа.
4. Тесты: `dotnet test`
